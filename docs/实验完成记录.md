# 实验完成记录

本记录在补充训练、新环境重训和本地推理核验实际完成后生成。原始预测、权重、图表和校验清单保存在D盘本地忽略目录，不自动上传。

## 已完成范围

- 核心矩阵扩展至12个噪声/样本量条件，三条方法路线、三个固定种子，共108组带噪结果；干净参考为四个样本量、三个种子。
- 对称/实例相关噪声10%/20%/30%的10-shot曲线齐全；30%下5/10/20/100-shot比较齐全。
- 六个条件下q=0.2/0.4/0.7/0.9/0.95、三个种子，共90组q结果，包含30组明确复用。主q仍为0.7。
- 原有模块/嵌入消融与删除、重标注、加权、取消OOF的清洗变体保留；新增开题指定的直接配对统计、逐条件目标检查和真实错误样例。
- 213个不重复最终模型，共1171500条保存预测的官方真值、指标、逐类表、矩阵、配置、验证选模、训练专用词表和权重重放通过。
- 36条五折OOF路线的分折、训练词表、清洗决策和折模型概率重放通过，共180个折模型。
- 新依赖环境重新训练IDN30%、10-shot全部三种子对照，12次最终拟合和15次OOF拟合完成。12组预测字节及选中模型参数与原运行相同；其他条件做核验/权重重放，未声称全部重训。
- MiniLM固定权重重新编码60750条嵌套子集样本，12份历史向量及IDN标签重建通过；不同子集中的同一文本重复编码按实际工作量计。

## 公开基线

SVM v2由预先固定的四项候选按验证准确率选出词频LinearSVC，ID准确率90.96%，相对论文91.0%差-0.04个百分点，±2个百分点数值检查通过。OOS召回13.30%，论文为14.5%。四个候选的验证预测和最终16500条测试预测均通过模型重放。

三个确定性SVM运行结果相同，标准差为0不表示泛化不确定性为0。原文未公开的求解器/表示选择单独披露；这是补充的公开模型重实现，不是原始代码精确复现。CNN v1 87.41%的未达标结果及SVM v1 88.24%的未达标结果保留。
