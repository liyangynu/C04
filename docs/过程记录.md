# 过程记录

## 2026-11-03：数据准备与噪声构造

### 实现

- 整理 CLINC150 数据规模、噪声设置、评价指标及阶段验收条件。
- 固定官方数据提交版本，核验六个划分和150类计数，保存下载信息及SHA256。
- 实现三种子、每类5/10/20/100条的嵌套抽样，生成18个干净数据与小样本文件。
- 实现对称噪声和实例相关噪声生成器，分离训练标签与审计真值。
- 生成36组对称噪声数据，保存逐样本翻转记录、转移矩阵及文件校验值。

### 验证

环境为 Python 3.12.14、NumPy 2.3.5。验证内容包括嵌套抽样、相同种子重放、精确翻转比例、无自翻转、拒绝评估/OOS数据、句向量ID对齐和输入数据不修改。结果见 `reports/stage1_tests.txt` 与 `reports/stage1_validation.json`。

官方划分经小写与空白标准化后，训练-验证有3条文本重合、训练-测试有2条重合。保留官方划分，并在检查报告中记录。
