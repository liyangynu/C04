# 核心噪声矩阵与样本规模扩展

本协议根据开题报告第6.2、6.4节冻结。目标是补齐10-shot核心噪声对照，并检查每类训练样本数变化时两种30%噪声的表现。原有10-shot、30%三方法结果直接复用，不重跑。

核心矩阵固定每类10条、种子17/42/2026，包括对称噪声10%、20%、30%和MiniLM句向量构造的实例相关噪声30%。每组比较CE、GCE(q=0.7)和五折OOF置信学习清洗后CE。项目已有对称30%和实例相关30%正式结果，本轮只增加对称10%和20%。

样本规模实验在每类5、10、20、100条下，比较对称30%和实例相关30%。每个设置含CE参考、GCE和置信学习，使用相同的三个种子与配对训练子集。10-shot各条件复用核心矩阵；其余规模的三种子干净CE参考单独补训。100-shot为官方完整ID训练集每类100条。置信学习每组使用五折OOF并记录额外训练成本。

所有新训练沿用 `formal_ce.json` / `formal_gce.json`，最多30轮、耐心5、验证macro-F1选模。噪声标签由固定协议产生，错标数量按目标比例取最近整数；同一shot和seed下对称比例的选样嵌套。实例相关噪声固定模型版本、温度和embedding批量大小。任何训练与清洗步骤均不得读取 `audit/` 中的干净标签；事后诊断在所有训练结束后运行。

预计新增81个最终模型拟合、120个OOF折拟合，共201个训练过程。模型顺序运行于单卡；48小时为上限，不因测试结果调整配置。每轮时间和峰值显存按现有训练日志记录。协议机器可读副本为 `configs/expanded_matrix_v1.json`。

主要指标为固定150类macro-F1，另报告准确率、MSP OOS AUROC、相对同种子同shot干净CE的F1保持率、耗时和显存。原开题设定的高噪声F1提升5个百分点、OOS AUROC下降容忍0.02作为目标/风险界限，不作为调参目标；按逐种子差值和区间报告，未达到的设置保留为失败分析。

旧5轮结果不并入本矩阵。该扩展是在已有探索结果后制定的阶段协议，不称为完全未观察测试集的预注册实验。统计推断在全部新结果完成后再统一更新。
