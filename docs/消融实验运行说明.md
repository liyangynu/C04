# 消融实验运行与核验

先按README准备固定CLINC150、GloVe和 `requirements-formal-lock.txt` 环境。范围与解释限制见[消融协议](消融实验协议.md)。本轮使用上一阶段发布的IDN观测标签，不需再次下载MiniLM。

## 完整训练

每个输出目录必须尚未存在。若已经重建 `data/formal_idn10_v2`，直接执行训练命令；再次复现时可为重建目录和输出目录另取名称。

```powershell
.\.venv\Scripts\python.exe -m c04.prepare_formal_data --results reports/stage3/formal_idn10_v2 --output data/ablation_idn10_input
.\.venv\Scripts\python.exe -m c04.run_ablations --source data/ablation_idn10_input/matrix.json --output artifacts/replay_ablations_idn10_v2 --device cuda
.\.venv\Scripts\python.exe -m c04.ablation_results --source artifacts/replay_ablations_idn10_v2 --results reports/replay_ablations_idn10_v2
.\.venv\Scripts\python.exe -m c04.analyze_ablations --results reports/replay_ablations_idn10_v2 --output docs/重跑消融结果
```

入口按清单顺序运行六个变体、每个三个种子，共18次新训练，随后独立评估。q=0.7的三次参考来自已发布 `reports/stage3/formal_idn10_v2/gce/`，不是本轮新训练。训练和选模均不读取测试结果；每次最佳检查点由官方验证宏F1选择。

## 仅核验发布结果

在新的Git检出目录准备官方数据后，可复用已安装环境进行核验，无需下载GloVe或执行训练：

```powershell
.\.venv\Scripts\python.exe -m c04.ablation_results --results reports/stage4/ablations_idn10_v2
.\.venv\Scripts\python.exe -m c04.analyze_ablations --output docs/阶段4消融结果
```

核验18组预测和混淆矩阵、均值与样本标准差；逐项检查配置仅修改协议字段，训练/验证数据与对应种子参考一致，词表只来自同一训练文本，环境记录一致。冻结嵌入额外保存初始和最佳矩阵，独立核对它们逐项相同。

完整模型权重不上传Git，保留在本地训练目录。冻结嵌入导出只是局部权重证据，不能凭它重新计算整个模型的预测；若要验证模型到预测的计算过程，需执行完整训练/评估入口。

q扫描同时报告验证和测试表现，仍保留q=0.7主配置。末状态模型参数数量和初始化随机数消耗发生变化，不能将配对差值解释为严格保持全部权重初值后的单一模块因果效应。本轮只覆盖IDN30%、10-shot，尚未扩展其他噪声和规模。
