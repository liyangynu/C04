# 实验补齐协议 v1

2026年11月19日，在新增训练前固定 `configs/completion_v1.json` 和 `configs/public_svm_v1.json`。已有主实验、负结果和CNN v1保留；本协议属于看过早期结果后的补充设计，不称预注册验证。

1. 补充10-shot下IDN10%和20%，各跑CE、GCE(q=0.7)、五折OOF清洗后CE，三个固定种子。共18次最终训练和30次OOF折训练。噪声仍采用固定MiniLM版本和温度0.2，沿用原协议的嵌套比例随机命名空间，不用测试数据构造或调节噪声。
2. q扫描补齐六个条件：10-shot对称10%/30%、10-shot IDN10%/30%，以及5-shot对称30%/IDN30%。每个条件固定q=0.2/0.4/0.7/0.9/0.95及三个种子。复用已完成的相同输入/配置结果，新增60次训练；q=0.7不因测试排序变更为其他值。
3. 增加开题指定的IDN30%、10-shot下置信学习减GCE的直接配对比较。Macro-F1和OOS AUROC分别报告三种子差值、95%配对t区间、t检验、精确Wilcoxon和多重比较校正。按实际结果逐条件判断F1提高0.05和AUROC下降不超过0.02的点估计目标；点估计达标不等于统计非劣。
4. 独立新虚拟环境重新安装固定依赖，先检查测试、预测及设备，再重训新增实验。环境复用本机同一Python基础解释器和GPU，不复用原虚拟环境的site-packages；输入数据和固定GloVe可通过校验后共享。原矩阵不宣称在新环境全部重训，训练重放的具体方法/条件另列。
5. 完成主实验、消融与清洗变体的本地最佳权重推理重放，核对5500条预测的类别和MSP分数；检查OOF折隔离、概率与清洗重放，以及本地证据清单。检查与实际重训分别计数，避免重复计算训练成本。

## 公开SVM参照

课程要求至少一个标准设置的公开基线。CNN v1未达标，继续保留该结论；新增原论文表2 Full/oos-train SVM，不把CNN改称通过。原文3.1节说明线性SVM与词袋表示，官方参数表给出onehot、linear、C=1。

固定为scikit-learn二元词袋 `CountVectorizer(binary=True)` 和 `SVC(kernel='linear', C=1)`，不使用LinearSVC替换SVC。分词正则、小写、unigram、求解器等未完整公开的实现选择在配置中明列，不称原代码精确复现。官方15000条ID+100条OOS训练，OOS为第151类；4500条ID和1000条OOS测试。无超参数搜索、阈值选择或概率校准。以ID准确率均值和论文91.0%作±2个百分点检查，并报告论文OOS召回14.5%的差值。三个种子全部报告；SVC确定性结果相同不代表进行了三次独立随机扰动实验。
