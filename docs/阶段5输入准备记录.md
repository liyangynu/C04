# 阶段5：扩展矩阵输入准备

## 2026-11-18：固定噪声输入生成

- 根据 `configs/expanded_matrix_v1.json` 添加 `c04.prepare_expanded_matrix`，只生成训练输入和隔离审计文件，不启动模型训练。
- 使用官方固定数据、seed 17/42/2026 和每类5/10/20/100条的嵌套子集。核心10-shot对称噪声包括10%、20%、30%；样本量扩展为5/20/100-shot对称30%和实例相关30%。10-shot IDN30%直接复用阶段3正式观测标签。
- 其他实例相关噪声向量由 `sentence-transformers/all-MiniLM-L6-v2` 固定revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`、batch size 64、CUDA导出。向量位于被Git忽略的 `artifacts/stage5_embeddings/`。
- 生成30个条件/种子输入，按目标率精确翻转37,800个标签。训练文件只含 `id/text/label`；原始标签与翻转掩码在单独的 `audit/labels.jsonl`。矩阵记录数据、噪声输入、审计文件和向量SHA256。
- 验收：42项自动测试通过；专项检查确认全部30组翻转总数正确、训练文件未包含审计字段、10-shot对称翻转集合按10%/20%/30%嵌套；重新生成的10-shot对称30%三种子训练文件与阶段1哈希逐一相同。
- 本记录只覆盖输入准备。计划中的81次最终模型拟合、120次OOF拟合以及公开CNN对照尚未执行；测试集指标仍未用于本阶段输入构造或参数调整。

## 重建命令

先准备官方数据并按 `requirements-idn.txt` 安装编码器依赖，再运行：

```powershell
python -m c04.sentence_embeddings --input data/processed/fewshot/seed_17/k_5.jsonl --output artifacts/stage5_embeddings/idn_s17_k5.npz --revision 1110a243fdf4706b3f48f1d95db1a4f5529b4d41 --device cuda
```

按 `seed=17/42/2026`、`shots=5/20/100` 对所有组合导出句向量后：

```powershell
python -m c04.prepare_expanded_matrix --output data/stage5_expanded --embeddings-template "artifacts/stage5_embeddings/idn_s{seed}_k{shots}.npz"
```

`data/` 与 `artifacts/` 不提交Git；从固定输入、编码器版本与脚本可重新生成。
