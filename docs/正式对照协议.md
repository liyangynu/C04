# 正式对照协议 v2（2026-11-16）

此前5轮试跑已显示小样本欠拟合，且旧清洗器只是阈值启发式。旧结果保留作探索记录，不当作完整置信学习结果。

本轮先固定10-shot、真实 MiniLM IDN30%、seed=17/42/2026。直接复用既有 CE 矩阵中的观测训练文件，不重新抽样或改变标签。此次设置在运行新对照前记录；制定时已知先前探索结果，并非从未观察过测试集的预注册研究。

- 最终分类器和五折 OOF：最多30轮、早停耐心5、验证宏F1严格上升选模；其余模型和优化器与原基线相同。CE、GCE(q=0.7)、清洗后CE均从头训练。配置为 `formal_ce.json`、`formal_gce.json`。
- OOF只用观测标签划分，每折独立词表；官方干净验证集用于选模，折外样本及测试集不参与该折训练或选模。清洗用 cleanlab 2.9.0 的校准置信联合和 `prune_by_noise_rate`，`min_examples_per_class=1`、`n_jobs=1`，禁止读取噪声审计真值或指定真实错标数。
- 固定150维概率；记录缺失观测类、折大小、每折训练/留出ID和完整概率。折外覆盖恰好一次且训练/留出不相交。清洗后每个已有观测类至少保留一条；不存在的类不补真值。
- 每个种子额外训练同预算的干净CE，仅用来计算F1保持率。各方法复用相同观测噪声；清洗后的词表允许仅依赖保留文本，因此初始化协议相同不代表词表矩阵逐项相同。
- OOF五模型成本单列，并纳入清洗路线总成本；计时含启动、输入扫描、训练和评估。PyTorch已分配/保留显存不同于整卡占用。
- 独立从原始预测重算指标。只做三种子的描述性配对比较，完整统计、其他样本量和噪声扫描留给后续阶段；不据本轮测试输出重新调阈值。

cleanlab：https://github.com/cleanlab/cleanlab ，AGPL-3.0；以依赖形式调用，没有复制其实现。Northcutt et al. (2021) 为方法来源。锁定环境与资产清单随结果保存。原5轮配置和结果不覆盖。

## 扩展一：对称30%（运行前固定）

下一组只将噪声类型改为对称30%，仍为10-shot、seed=17/42/2026。沿用上述模型、30轮上限、耐心5、GCE q=0.7和cleanlab 2.9.0清洗设置，不根据IDN的测试分数调参。每个种子精确翻转450/1500条，使用既有对称噪声随机命名空间；训练数据与阶段1相同输入的SHA256核对后再运行。

重新运行三个干净CE参考，以及CE、GCE、五折OOF和清洗后CE，共27次训练。独立导出在 `reports/stage3/formal_sym10_v2/`，不覆盖IDN结果。清洗诊断只在全部训练后读取干净训练标签。新矩阵显式保存噪声类型，避免重建对称标签时被错误标成IDN。

本组用于补齐两种噪声下的同预算配对证据；三种子仍只作描述性比较，不据此宣布显著性、非劣性或达到所有课程目标。其他样本量、比例、消融和公开基线继续单独安排。
