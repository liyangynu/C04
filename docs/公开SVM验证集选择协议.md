# 公开SVM验证集选择 v2

2026年11月19日，v1三次固定二元词袋SVC均得到ID准确率88.24%，比论文91.0%低2.76个百分点，未达±2个百分点。全部结果保留。原文给出线性SVM、词袋/onehot和C=1，没有完整披露计数表示及多分类求解目标。

本轮在新增拟合前固定 `configs/public_svm_validation_v2.json`，只比较四个候选：binary/count词袋 × SVC/LinearSVC，C均为1。SVC采用线性核；LinearSVC为one-vs-rest、L2正则和squared-hinge，不把两者说成相同优化目标或恢复了原始代码。分词、小写和unigram继续沿用v1。

候选仅使用官方训练集拟合词表和模型，以官方ID+OOS验证集准确率选择；相同时按配置中的候选顺序决定。选择记录写盘后才读取测试数据，测试集不参与候选排序或停止条件。固定候选一轮后不追加搜索。选中的设置按17/42/2026运行，报告全部值及模型重放；确定性结果相同不等于有三组随机扰动的统计证据。

本轮是已知v1测试结果后的补充实现选择，不称预注册或原代码严格复现。单独报告ID准确率相对论文91.0%的差值、OOS召回相对14.5%的差值及实现缺项。主BiLSTM/GCE/置信学习实验不因此改动，CNN v1及SVM v1的未达标记录保留。
