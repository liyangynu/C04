# IDN30%、10-shot 消融协议

2026-11-17，在本轮训练开始前固定。沿用v2的三种子17/42/2026、同一批观测IDN30%标签、最多30轮、早停耐心5、验证宏F1选模。已知前两阶段探索结果，本组不是未接触测试集的预注册研究。

以已发布GCE(q=0.7)、可微调GloVe、注意力BiLSTM为参考，固定三组消融：

1. 模型模块：注意力汇聚改为双向LSTM最终有效状态拼接。其他设置保持参考值；不以补零后的最后一步代替真实最终状态。
2. 词向量：冻结GloVe嵌入，保留注意力及q=0.7。检查最佳模型的嵌入矩阵与初始矩阵逐项相同。
3. 参数敏感性：保持完整模型，q取0.2/0.4/0.7/0.9/0.95。q=0.7复用上一阶段三种子记录，其他四个值各从头训练三种子，不按测试分数挑选新的主参数。

本轮新增18次训练：末状态3次、冻结嵌入3次、四个新q值12次。不重新训练OOF，不增加噪声比例和样本量。配置清单为 `configs/ablation_idn10_v2.json`；每项只修改清单所列字段，输出各自配置快照。

相同种子表示相同随机初始化协议。移除注意力会改变参数形状和随机数消耗，不能声称共享层初始参数逐项相同。本轮比较的是指定配置下的模型行为；相同轮数上限和早停规则也不等于相同实际更新次数。

导出每次5500条预测、混淆矩阵、逐类F1、曲线、配置和日志，独立重算指标、核对输入哈希和变更字段。三种子差值只作描述性分析；不据测试均值宣布统计显著或将最佳q写回主配置。验证和测试的q趋势均保留，提醒后续调参需单独协议。
