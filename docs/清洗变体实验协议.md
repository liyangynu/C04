# IDN30%、10-shot 清洗变体协议

2026-11-17，训练前固定。本轮已经知道删除路线负结果，属于探索之后的固定补充实验，不声称从未观察过测试集。

沿用150类、IDN30%、10-shot、17/42/2026三个种子，注意力BiLSTM、CE、30轮上限、耐心5、验证宏F1选模。主模型和GCE参数不变。本轮新增12次训练，各三种子：

1. CE重跑：同一观测输入从头训练。独立测试结果用于核对新增权重接口未改变普通训练；最佳模型还用于产生训练内概率。
2. OOF重标注：复用已发布的五折概率及cleanlab 2.9.0标记，仅把标记样本改为概率argmax，其余保持观测标签。保留1500条，固定150类输出；重标注可能造成训练类别缺失，记录但不借助真值补类。这是本项目定义的硬重标注变体，不声称等于cleanlab官方重标注算法。
3. OOF加权：保留全部文本与观测标签，原观测标签的OOF概率裁剪到[0.05,1]，再除以全训练集均值。训练目标为batch内 `mean(w_i * CE_i)`；不除以每个batch的权重和。权重按ID与打乱样本对齐，侧文件校验哈希并纳入恢复训练指纹。该规则为固定启发式，不是对噪声转移矩阵的无偏校正。
4. 取消OOF后删除：使用本轮CE模型对其自身训练样本的概率，沿用相同校准置信联合、噪声率剪枝及已有观测类至少留一条的规则，然后从头重训。训练内打分故意取消折外隔离，只作消融，不把它当作OOF概率或无泄漏标签质量估计。

已有OOF删除和带噪CE参考从 `reports/stage3/formal_idn10_v2/` 复用。前三个OOF处理变体共用同一概率资产和标记规则；不以已知450条错标数强制删样，不按测试结果更改权重下限/标记阈值。变体清单见 `configs/cleaning_variants_idn10_v2.json`。

重标注/加权沿用完整训练词表；删除词表仅由保留文本建立。各路线实际样本量、更新数和训练成本分开记录；复用五折资产不等于完整路线没有OOF成本，原有五折训练成本注明来源。取消OOF路线计入CE打分模型训练和最终重训两项，不将CE测试/绘图开销当作纯清洗算法成本。

全部模型完成后才读取干净训练标签做误删、重标注正确性和加权诊断，不参与训练或阈值选择。保存输入处理决策、完整概率、权重、逐样本测试预测和日志，独立重放。三种子只作描述性配对，不据此宣布显著性；其他样本量/比例、正式统计和公开基线留待后续。
