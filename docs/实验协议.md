# C04 实验协议 v1

本协议规定数据版本、噪声构造、训练对照和统计口径。开题报告未明确的数值以实施选择注明，并在实验前固定。

## 数据与隔离

CLINC150 官方仓库 `clinc/oos-eval`，数据提交版本 `48a0e1cff8f43dd4d0836ecb4ed5df08733e3d2e`，路径 `data/data_full.json`。下载使用固定提交 URL，在线下载和本地导入均校验配置中的SHA256。处理清单记录源路径、原文件校验值和类别映射校验值。

150 类，训练/验证/测试每类 100/20/30 条；OOS 训练/验证/测试为 100/100/1000。类别名称排序后映射为 0..149，OOS 固定 -1。模型不将 OOS 当作第 151 个训练类别；OOS 训练数据仅保存，不参与当前三条分类路线训练。

每个种子先独立排列每个类别训练样本，再取前 5/10/20/100 条。5⊂10⊂20⊂100，方法之间复用相同训练 ID。验证和测试保持全量官方干净划分。词表只能使用训练文本，不能从验证/测试/OOS 扩充。句子编码器不在验证/测试集上微调；噪声原型仅使用选定的训练子集。

原始干净训练标签只用于人工构造与事后噪声诊断。`data/noisy/.../train.jsonl` 为训练接口，`audit/labels.jsonl` 是独立审计接口；后续清洗、调参不得读取审计真值。清洗阈值不能借助真实错标率、真实错误掩码或测试指标选择。

官方划分按小写与空白标准化后有训练-验证 3 条、训练-测试 2 条文本重合。当前严格保留官方划分，不因此改动数量。若后续做去重敏感性分析，应作为单独设置，不能混入公开基线对照。

## 噪声定义

种子 17/42/2026 为实施选择；固定 NumPy 2.3.5。样本按稳定 ID 排序；随机抽样、噪声选择、噪声标签使用互相独立的随机命名空间。

噪声数量为 `floor(N*rate+0.5)`，因此目标比例因整数约束最多偏差 0.5/N。对称噪声无放回选样本，目标标签在其余 149 类均匀抽取。相同种子、相同样本集下，10%/20%/30% 使用嵌套翻转集合与一致的错标标签，降低比例扫描的无关随机差异。

实例相关噪声采用本课题明确规定的合成协议：

1. 导入真实冻结句子编码器向量，NPZ 必须含 `ids`、`embeddings`、`encoder_id`、`encoder_revision`，禁止 pickle；按 ID 对齐并保存文件 SHA256。编码器名称和不可变版本将在阶段 3 选定并固定。
2. 归一化训练样本向量，按原始训练标签计算类别原型；目标替代类按样本到其他类原型的余弦相似度 softmax 抽取，真类概率严格为 0。
3. 用“最相近其他类相似度减去自身类留一原型相似度”描述样本歧义。Gumbel top-k 进行带权无放回选样，歧义大的样本更易被选为错标样本，数量仍精确控制。
4. 温度初值 0.2 为实施选择，与噪声配置一起记录；不使用测试表现调节噪声。

该协议的翻转倾向和目标类分布均依赖样本向量，属于本项目的合成噪声设置。当前真实 IDN 数据尚未生成；合成向量测试仅用于检查生成器的语义邻近性质。

主对照包括对称10/20/30%和IDN30%；为绘制两类噪声的比例曲线，增加IDN10/20%。完整扫描在训练成本测量后确定运行安排。

## 后续训练与比较约定（尚未实现）

GloVe 100d 可微调嵌入、BiLSTM、注意力池化、150 类分类头。AdamW，学习率1e-3，batch 64，最多5轮，以验证macro F1选最佳检查点。隐层维度、dropout、weight decay和早停耐心在阶段2固定。若5轮明显欠拟合，记录该结果，延长训练作为单独的补充实验。

CE、GCE(q=0.7)、置信学习清洗的最终分类器使用相同初始化协议、数据及训练预算。置信学习5折 OOF + 重训的成本必须单独计入：最终模型轮数相同不意味着总算力相同。OOF 每个样本只由未见过它的模型产生预测；每个折内词表只使用该折训练文本。

5-shot 经噪声后某观测类可能少于5条甚至为空，不得拿审计真值补分层。计划使用观测标签分层；不足5条时采用平衡非分层五折并记录告警，保持固定150维概率输出；有缺类时清洗估计必须显式处理，清洗后避免删除某类全部可用样本。具体置信学习库兼容行为在阶段 3 验证后冻结。

闭集 macro F1 在固定150类上计算；OOS 为正类，检测分数为 `1-max(softmax(logits))`，测试 ID + OOS test 用于 AUROC。阈值指标若加入，只在验证 ID/OOS val 上确定阈值。F1 保持率与相同种子/样本量的干净 CE 基线配对，不跨样本规模混比。

## 验收、统计与负结果

高噪声条件下的目标为macro F1绝对增加0.05，未达目标的设置纳入失败分析。OOS AUROC下降容忍度暂定0.02，属于实施选择，修订须在查看测试结果前记录。非劣结论需结合差值区间，不能仅依据点估计或p>0.05判断。

三种子报告样本标准差(ddof=1)。只有3个配对点时正态性诊断不可靠，精确双侧Wilcoxon最小可达p=0.25。预先报告双侧配对t检验及精确Wilcoxon敏感性结果，并说明小样本局限；若需更强统计结论，预先扩展到至少10种子并保持配对。多组主要比较同时进行时报告多重比较调整，消融结果与主要假设检验分别报告。

消融包括模型模块、q∈{0.2,0.4,0.7,0.9,0.95}、删除/重标注/加权/取消OOF、噪声类型与比例、小样本数量。先测量核心训练成本，再确定单GPU≤12GB、48小时内可运行的实验矩阵。预算调整、延期和未运行项单独记录。

CLINC150原论文使用GloVe初始化CNN等分类器，并报告150类准确率和OOS召回率；它不包含本项目的BiLSTM-Attention、宏F1和MSP AUROC设置。因此这些论文数值不能直接作为该BiLSTM模型的“±2%”验收值。本项目保留报告要求的BiLSTM基线，并将论文CNN准确率作为数据协议背景，模型与指标差异在结果中注明。GloVe引用采用Pennington, Socher, Manning, EMNLP 2014，替换开题报告中对应的Mikolov 2013引用。
