# 扩展矩阵代码核验

## 本轮修改

- 续跑时将旧方法名 `cl_ce` 与 `confident_learning` 视为同一路线，避免旧进度记录导致重复训练；不改写历史记录。
- 每次准备输入时清空上一个条件的向量来源。复用IDN10观测标签时，新的输入清单将 `encoder` 记为 `null`；原始来源仍由 `reuse_source_sha256` 和已发布阶段3记录标识。旧清单不覆盖。
- 新构造IDN的向量必须匹配 `configs/expanded_matrix_v1.json` 中的编码器ID和固定revision；不匹配时拒绝生成。
- 增加 `c04.check_expanded_predictions`，从逐样本预测重算扩展矩阵的结果。

本轮提交代码、测试和使用说明。开题报告、要求图片、虚拟环境、数据、权重，以及本轮新生成的大批实验产物不上传GitHub。先前已发布的实验记录保留。

## 运行方法

在项目根目录、官方数据和本地阶段5训练产物均已准备好的环境中运行：

```powershell
.\.venv\Scripts\python.exe -m c04.check_expanded_predictions
```

默认输入为：

- `artifacts/stage5_expanded_runs/progress.json`：原始进度记录。
- `docs/阶段5扩展实验结果.json`：已发布汇总。
- 进度记录指向的本地训练目录，以及复用的 `reports/stage3/` 结果。
- `data/processed/`：固定官方划分与标签映射。

默认核验报告写入本地 `artifacts/stage5_prediction_check.json`，可通过 `--report` 改变输出位置。该命令只读已有实验，不启动训练。

检查90组不重复带噪结果、12组干净参考，共561000条预测。逐组核对测试ID/真值、宏F1、准确率、OOS AUROC、混淆矩阵和逐类表，并检查冻结训练配置、种子、验证选模轨迹和数据指纹。再由重算值核对保持率、均值/样本标准差及40项配对统计。旧别名及复用记录按实际来源处理，重复运行不重复计入。

## 实际验证与范围

2026年11月19日，本地102组预测与40项配对比较核验通过。修正后的准备入口在新目录重建30组输入，训练文件和审计标签的SHA256均与原矩阵一致；没有重新训练或改变已报告指标。

55项测试通过，包含新增的旧别名续跑、错误模型/版本拒绝、复用标签独立准备，以及预测真值、逐类F1、矩阵列标签、非有限OOS分数的故障检查。

该检查需要未入库的本地扩展实验产物，不能称为仅克隆GitHub即可验证全部阶段5预测。它也不等于模型权重重放、OOF概率重放、编码器重新推理或新依赖环境训练；原有输入/OOF审计仍由 `c04.stage5_results` 单独执行。完整阶段5证据尚未全部发布，公开CNN数值验收仍未通过。
