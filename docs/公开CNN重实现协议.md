# 公开 CNN 重实现 v1

2026-11-19，在本轮CNN训练前固定。参照 Larson et al. (2019) 表2 Full/oos-train 和官方仓库 `hyperparameters.csv`；原始材料未包含完整实现，因此本轮为按论文公开参数重实现，不称原代码逐项复现。

沿用公开参数：可微调GloVe、200个卷积滤波器、valid/stride=1卷积、卷积softmax、300维ReLU全连接层、dropout 0.6、batch 16、151类softmax分类。项目输出logits，由交叉熵完成输出softmax。

补充选择在 `configs/public_cnn_v1.json` 明列：100维词向量、单个宽度3窗口、每个位置沿滤波器维softmax、按真实长度掩码的全局最大池化、全连接层前后dropout、项目分词器与长度40、Adam学习率0.001、梯度裁剪5。短于窗口的句子补零至3，仅保留一个有效卷积位置。上述补充未由论文完整指定，固定后不根据测试值换参数。

官方15000条ID训练与100条OOS训练合并；OOS映射为第151类。词表只由这15100条训练文本建立，不读取验证/测试文本。验证为3000条ID与100条OOS，最多30轮、耐心5，以151类验证准确率选最佳检查点。三个种子17/42/2026顺序运行；最佳模型选好后才读取测试集，测试为4500条ID与1000条OOS。模型与主BiLSTM实验隔离。

直接比较论文ID accuracy=91.2%、OOS recall=18.9%；ID预测成OOS计为ID错误，OOS argmax=150计为正确检测。不在测试集选阈值，未用OOS验证选择额外阈值。附报150个ID类macro-F1（保留拒识造成的漏判）、以p(OOS)打分的AUROC，后者与主实验MSP打分区分。

三个种子的全部结果均保留，报告均值、样本标准差和逐种子值。±2个百分点按ID准确率均值与91.2%的绝对差检查；无论是否达到，均不得把该范围当作原论文缺失实现细节已恢复的证明。负结果保留，不为了达标更改配置。
